# qiudai0627/homebrew-tap

Official Homebrew Tap for **[agy-usage](https://github.com/qiudai0627/agy-usage)** — zero-dependency local real-time quota & token usage monitor for Google Antigravity (`agy`).

## Install

```bash
brew install qiudai0627/tap/agy-usage
```

After installing the CLI, wire the `/statusline` bar, macOS notch-safe floating pill, and local dashboard (`http://127.0.0.1:18420`) with:

```bash
bash "$(brew --prefix)/opt/agy-usage/libexec/install.sh"
```
